# 本地打标环境

本项目的 YOLO QR 检测只需要一种矩形框标签：`qr`，类别编号为 `0`。当前训练脚本读取 Ultralytics YOLO 数据集，例如 `runtime/datasets/processed/qr_yolo_v2/data.yaml`。

## 启动本地 Label Studio

推荐使用本地 Label Studio，不使用云端服务，也不需要读取 `.env` 或任何 NVIDIA 密钥。

如未安装过 Label Studio，先安装一次本地工具：

```bash
uv tool install label-studio
```

如果网络刚好不可用，但本机已经缓存过安装包，可以使用：

```bash
uv tool install --offline label-studio
```

```bash
uv run python scripts/start_label_studio_qr.py --port 8080
```

脚本会准备以下本地目录：

- `runtime/labeling/images/`：放准备打标的图片。
- `runtime/labeling/exports/`：放导出的标注结果。
- `runtime/labeling/label-studio/`：Label Studio 本地数据库和配置。

如果 8080 端口被占用，可以换端口：

```bash
uv run python scripts/start_label_studio_qr.py --port 8081
```

首次打开页面后，按 Label Studio 提示创建本地账号。新建项目时，在 `Labeling Setup` 的代码模式中粘贴 `labeling/label_studio_qr.xml` 的内容。这个配置只提供一个矩形标签：`qr`。

## 怎么打标

1. 每张图里所有可见的二维码或条码区域都要框出来。
2. 标签只能选 `qr`，对应 YOLO 类别 `0`。
3. 框要贴合码图主体；如果静区清晰可见，可以一起包含；不要把发票文字、印章或表格框进去。
4. 模糊、遮挡、旋转、很小的码也要照实框出，只要人眼能确认目标。
5. 一张图有多个码时，每个码各画一个矩形框。
6. 不确定是否是二维码/条码时先跳过，单独记录，避免把票面文字误标成 `qr`。

## 导出和放置

Label Studio 标完后优先导出 YOLO 格式。最终数据集目录应保持这种结构：

```text
dataset/
  data.yaml
  images/
    train/*.png
    val/*.png
    test/*.png
  labels/
    train/*.txt
    val/*.txt
    test/*.txt
```

每个标签文件一行一个框：

```text
0 x_center y_center width height
```

坐标必须是归一化到 `[0, 1]` 的 YOLO 格式。`data.yaml` 的类别必须是：

```yaml
names:
  0: qr
```

## 打完标后校验

训练前先运行校验脚本：

```bash
uv run python scripts/validate_yolo_dataset.py --data runtime/datasets/processed/qr_yolo_v2/data.yaml
```

校验会检查：

- `train`、`val`、`test` 图片目录存在。
- 每张图片都有同名 `.txt` 标签文件。
- 标签每行都是五个 YOLO 字段。
- 类别只能是 `0`。
- 坐标均在 `[0, 1]` 内，宽高大于 `0`。

校验通过后再训练：

```bash
uv run python scripts/train_yolo_qr.py --data runtime/datasets/processed/qr_yolo_v2/data.yaml --model yolov8n.pt --epochs 30 --imgsz 960 --device 0
```

## 备用桌面工具

如果不想用浏览器工具，也可以用支持 YOLO 导出的桌面打标工具。项目提供 `labeling/classes.txt`，内容只有一行 `qr`。无论使用哪种工具，最终都要用 `scripts/validate_yolo_dataset.py` 校验后再训练。
