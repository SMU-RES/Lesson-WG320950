# QR YOLO v2 dataset sources

- kolabit/qr-codes, Apache-2.0 repository license, one QR class; local subset copied from runtime/datasets/qr-codes.
- mapo80/barcodes, CC BY-SA 4.0 Hugging Face dataset, QRCode annotations converted from COCO to single YOLO class qr; source card reports 30,727 images and 6,003 QRCode instances.

All data stays under ignored runtime/datasets and is not for commit.
